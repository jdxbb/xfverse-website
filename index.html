About XFVerse

让每部电影找到 懂它的人

XFVerse
开源智能观影发现平台

XFVerse 是面向本地硬盘与 WebDAV 用户的智能观影发现平台。它把媒体库管理、元数据搜刮、观影统计和 AI 推荐整合在一个本地优先的桌面应用中。基于 mpv 内核与 SQLite 数据库，所有核心数据保留在本地，让私人片库从「存着」变成「懂你」。

FAQ

常见问题

基础功能完全免费：扫描、搜刮、影视墙、本地播放、观影统计。AI 画像与推荐为可选模块，需自行配置 API 端点。

支持本地文件夹与 WebDAV 两种来源。自动通过 TMDB / OMDb 获取海报、简介、演员等元数据。

三路并行策略：观影 DNA 偏好洞察、跨类型探索、评分与情绪匹配。候选池自动去重，每批推荐 3 部，附理由。

不会。核心数据存储在本地 SQLite。TMDB / OMDb 仅传输影片名称，AI API 仅传输脱敏后的偏好特征。

基于 mpv 内核，支持 MKV、MP4、AVI、TS 等主流格式，以及 HDR、蓝光字幕、多音轨。

通过 WebDAV 可跨设备访问片库与流式播放。本地数据库暂不支持自动同步，未来版本计划加入。

未来版本将开放插件 API，支持自定义数据源、推荐策略与界面主题。欢迎关注 GitHub 路线图。
