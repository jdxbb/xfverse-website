快速开始

XFVerse 是一款面向本地硬盘与 WebDAV 用户的智能观影发现平台。它把媒体库管理、元数据搜刮、观影统计和 AI 推荐整合在一个本地优先的桌面应用中。本文档将引导你完成从安装到日常使用的完整流程。

XFVerse 当前处于活跃开发阶段，基础功能永久免费。AI 画像与推荐为可选增强模块，需自行配置 API 端点。

第一步：安装运行时

XFVerse 基于 .NET 8 构建，运行前需安装 .NET 8 Desktop Runtime (x64)。安装包启动时会自动检测运行环境，如未安装会提示并引导下载。也可以手动从 Microsoft 官网下载：

https://dotnet.microsoft.com/download/dotnet/8.0

选择 "Desktop Runtime" → Windows x64 版本，下载并安装即可。

第二步：下载 XFVerse

从 下载页面 获取最新版本安装包。解压到任意目录后，双击运行 XFVerse.exe。首次启动时软件会创建本地数据库和配置文件，默认存储在用户目录下。

第三步：添加片源

启动后进入「扫描」页面。点击「本地目录」添加包含影片文件的文件夹，或点击「WebDAV」配置远程服务器。添加完成后点击「开始扫描」，软件会自动遍历目录、识别影片并匹配 TMDB 元数据。

扫描完成后，返回首页即可看到海报墙。首次使用建议先添加 1-2 个文件夹测试识别效果，确认无误后再大规模导入。

安装与环境

系统要求

  • 操作系统：Windows 10 / 11（64 位），Windows 7/8 未测试
  • 运行时：.NET 8 Desktop Runtime (x64)
  • 内存：至少 512MB 可用内存
  • 磁盘：至少 200MB 可用空间（不含影片文件）
  • 显卡：支持 DirectX 11 的显卡（mpv 播放要求）

网络依赖（可选）

  • TMDB API：用于获取影片元数据（海报、简介、演员、评分）。需要 TMDB API Key（软件内置默认 Key，也可自行申请）
  • OMDb API：辅助元数据匹配，需要 OMDb API Key（可选）
  • OpenAI 兼容 API：用于 AI 画像生成与智能推荐。支持 OpenAI、DeepSeek 等兼容接口
  • OpenSubtitles API：在线字幕搜索（可选，需在设置中配置）
核心功能（扫描、搜刮、影视墙、本地播放、观影统计）完全离线可用。仅元数据在线匹配和 AI 功能需要网络连接。未配置 API 不影响基本使用。

扫描与搜刮

本地文件夹扫描

在扫描页面选择「本地目录」标签，点击「添加文件夹」选择包含影片文件的目录。XFVerse 会递归遍历所有子文件夹，自动区分电影和电视剧。

扫描过程中可以实时看到识别进度。扫描完成后，已识别的影片会自动出现在首页媒体库中。未识别的影片会标记为「未识别」，可手动进行修正。

支持添加多个文件夹同时管理。每个文件夹独立维护扫描状态，可以分别重新扫描或移除。

文件命名建议

为提高自动识别准确率，建议遵循以下命名规范：

# 电影
/电影/Inception (2010).mkv
/电影/The Matrix (1999).mp4
/电影/肖申克的救赎 (1994).avi

# 电视剧
/电视剧/Breaking Bad/Season 01/Breaking Bad S01E01.mp4
/电视剧/Breaking Bad/Season 01/Breaking Bad S01E02.mp4
/电视剧/权力的游戏/Season 01/Game of Thrones S01E01.mkv

关键要素：影片名称 + 年份（电影）或 剧名 + SxxExx（电视剧）。年份和季/集编号是自动匹配 TMDB 最重要的依据。

手动修正

自动识别可能因文件名不规范、年份缺失或同名影片而匹配错误。在媒体库中右键任意影片，选择「修正识别」打开修正弹窗：

  • 输入影片名称搜索 TMDB 数据库
  • 从搜索结果中选择正确的条目
  • 确认后系统会更新海报、简介、演员等全部元数据
  • 修正结果会持久保存，重新扫描不会覆盖手动修正

电视剧支持

识别规则与命名

XFVerse 能够自动识别电视剧的季（Season）和集（Episode）结构。识别依赖文件名中的季/集标记，推荐格式如下：

S01E01  → 第 1 季第 1 集
S02E05  → 第 2 季第 5 集
1x01    → 第 1 季第 1 集（备选格式）

目录结构建议为 剧名/Season XX/ 格式，软件会据此自动分组。如果未使用 Season 子目录，只要文件名包含 SxxExx 标记，仍可正确识别。

特殊分集（如 SP、OVA、剧场版）建议放在 Season 00 或 Specials 目录下，并在修正识别时手动绑定 TMDB 特殊集条目。

剧集浏览

在媒体库中点击任意电视剧海报进入剧集详情页，页面展示：

  • 剧集信息：海报、简介、播出年份、类型标签
  • 季列表：以标签页形式切换不同季
  • 集列表：每集显示标题、时长、已看/未看状态
  • 快速跳转：点击任意未看集可直接从该集开始播放

播放进度与状态同步

系统会为每一集独立记录播放进度和观看状态：

  • 关闭播放器时自动保存当前播放位置
  • 下次打开同一集时从断点续播
  • 播放超过 90% 自动标记为「已看」
  • 可在剧集详情页手动切换「已看/未看」状态

数据刷新

重新扫描目录时，系统会自动检测新增的集数和文件：

  • 新发现的集数自动加入媒体库并标记为「未看」
  • 已存在的影片不会重复添加，仅更新元数据（如有变化）
  • 支持手动触发单个目录的重新扫描

媒体库管理

影视墙浏览

首页以海报墙形式展示所有已识别影片。支持以下浏览方式：

  • 全部影片：按添加时间或标题排序
  • 分类筛选：按类型（动作、剧情、科幻等）过滤
  • 年份排序：按上映年份升序或降序排列
  • 评分排序：按 TMDB 评分从高到低
  • 搜索：顶部搜索栏支持按标题快速查找

每张海报卡显示影片标题、年份、TMDB 评分。鼠标悬停可预览简介。

播放源管理

每部影片可关联多个播放源（不同分辨率、不同编码版本、本地文件与 WebDAV 文件混合）：

  • 在影片详情页查看所有已关联的播放源
  • 点击「播放」使用默认源直接启动 mpv 播放器
  • 点击播放源列表中的某个源可指定使用该源播放
  • 默认播放源可在详情页中手动设置
  • 未关联任何播放源的影片标记为「无播放源」状态

剧集视图

剧集详情以季为单位分组展示。每集显示标题、时长和播放进度条。已看集数显示绿色标记，当前正在看的集数高亮显示。

点击任意集可直接播放，播放器会自动加载对应文件。播放完成后系统询问是否继续播放下一集。

浅色 / 深色主题

XFVerse 支持浅色和深色两种视觉主题，可在设置页面随时切换：

  • 浅色主题：淡粉白背景，白色卡片，适合日间使用
  • 深色主题：深灰背景，深色卡片，适合夜间或暗光环境
  • 播放器界面固定使用深色模式（不跟随主题切换）以保证沉浸式观影体验

发现与推荐

发现页是探索新内容的入口，包含榜单浏览和 AI 推荐两大模块。页面顶部可切换电影/电视剧分类。

榜单浏览

提供 TMDB 三大官方榜单，实时更新：

  • 热门（Popular）：当前全球最受关注的影片
  • 高分（Top Rated）：历史评分最高的影片
  • 趋势（Trending）：今日/本周热度上升最快的影片

点击任意榜单影片可查看详情并直接播放（如果本地已存在该影片）。未收录的影片显示为元数据卡片，可添加到「想看」列表。

AI 推荐

配置 AI API 后，系统会根据你的观影历史生成个性化推荐。推荐包含：

  • 推荐影片海报和基本信息
  • 每条推荐附带可解释的推荐理由
  • 「喜欢」和「不感兴趣」反馈按钮，帮助 AI 持续学习你的偏好

AI 推荐需要至少 20 部已看影片才能生成有效画像。观影记录越多，推荐越精准。

推荐策略

XFVerse 采用三路并行推荐策略，每轮生成 3 部推荐：

  • 偏好洞察：基于观影 DNA 和类型偏好，推荐你可能喜欢但未看过的同类影片
  • 跨类型探索：在你不常看的类型中挑选高分影片，帮助你拓展观影边界
  • 评分匹配：基于情绪标签和评分分布，匹配与你看过的高分影片风格相似的作品

三路候选池经过水印去重后合并输出，确保每次推荐不重复且覆盖不同维度。

观影统计

观影洞察页提供多维度的数据分析和可视化，帮助你了解自己的观影习惯和偏好。所有统计仅基于本地数据计算，不会上传。

统计总览

  • 已看：累计观看的影片总数（含电影和电视剧集）
  • 喜爱：标记为「喜爱」的影片数量
  • 想看：已加入「想看」列表的影片数量
  • 不想看：标记为「不想看」的影片数量

支持「全部」和「本月」两种时间范围。切换后所有统计卡和图表同步更新。趋势统一显示为「相比上个月」。

日历热力图

日历视图以 GitHub 贡献图风格展示每日观影频率：

  • 每个格子代表一天，颜色越深表示当天观看的影片越多
  • 鼠标悬停显示当天具体观看了哪些影片
  • 点击任意日期跳转到当天的观影历史记录
  • 支持切换不同月份查看

图表分析

系统提供以下维度的图表分析：

  • 类型分布：饼图/环形图展示你最常看的电影类型
  • 情绪标签：热力图展示观影的情绪倾向（紧张、温馨、刺激等）
  • 场景分布：分析影片场景标签的分布情况
  • 时段分析：按小时/星期展示你的观影时间段偏好
  • 工作日 vs 周末：对比工作日和周末的观影量差异
统计图表需要至少观看 5 部影片才能生成有效数据。数据不足时显示「数据不足」提示而非空白图表。

WebDAV 配置

XFVerse 支持通过 WebDAV 协议直接访问远程服务器上的影片文件，无需下载到本地即可浏览元数据和流式播放。

连接设置

在扫描页面选择「WebDAV」标签：

  • 服务器地址：输入完整的 WebDAV 服务 URL（如 https://example.com/dav/）
  • 用户名：WebDAV 服务的登录用户名
  • 密码：对应的登录密码
  • 点击「测试连接」验证配置是否正确
  • 连接成功后，点击「开始扫描」遍历远程目录

支持 HTTP 和 HTTPS 协议。自签名证书需要在系统证书存储中受信。

WebDAV 密码使用 AES 加密后存储在本地数据库中。完整 URL、账号和密码不会在任何日志、错误提示或 UI 中明文展示。

流式播放

通过 WebDAV 连接的影片可以直接流式播放：

  • 点击播放后，mpv 直接从远程服务器读取视频流
  • 无需预先下载完整文件到本地
  • 支持拖动进度条跳转（取决于服务器是否支持 Range 请求）
  • 播放体验取决于网络带宽和服务器性能，建议至少 10Mbps 带宽
  • 高码率影片（4K HDR 等）建议在局域网环境下播放

AI 画像与推荐

AI 画像是 XFVerse 的核心特色功能。通过分析你的观影记录，系统能生成详细的观影人格报告和个性化推荐。此功能需要配置 OpenAI 兼容 API。

观影人格

系统基于观影记录生成以下维度的分析：

  • 23 种观影人格：如「硬核科幻迷」「文艺片鉴赏家」「动作片狂热者」「纪录片爱好者」等
  • 6 维观影 DNA：类型偏好、情绪倾向、场景偏好、年代偏好、语言偏好、节奏偏好
  • 口味象限：四象限定位图（主流/小众 × 商业/艺术），可视化你的观影偏好位置
  • 看得多 vs 真喜欢：对比你观看量最多的类型和评分最高的类型，发现「真正喜欢的」和「习惯性观看的」差异
观影人格需要至少 20 部已看影片才能生成。数据不足时显示「数据不足」状态和预计需要多少部影片。

API 配置

在设置页的「AI 配置」区域填写以下信息：

API Endpoint: https://api.openai.com/v1
Model: gpt-4o
API Key: sk-xxxxxxxxxxxxxxxx

# 也支持其他兼容服务
API Endpoint: https://api.deepseek.com/v1
Model: deepseek-chat

点击「测试连接」验证 API 可用性。配置成功后，AI 推荐和画像生成功能即刻启用。API 调用按实际使用量计费（取决于你的 API 服务商）。

隐私说明

AI 功能的隐私保护机制：

  • 数据脱敏：API 调用仅传输观影偏好特征（类型分布、评分统计、情绪标签比例），不传输影片名称、文件路径、个人身份信息
  • 本地优先：所有原始观影记录存储在本地 SQLite，不会自动上传
  • 可选关闭：AI 功能完全可选，不配置 API 不影响软件其他功能正常使用
  • 缓存机制：同一批观影数据的画像分析结果会缓存，避免重复调用 API
