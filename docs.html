快速开始

XFVerse 是一款面向本地硬盘与 WebDAV 用户的智能观影发现平台。本文档将帮助你快速上手。

当前处于活跃开发阶段，基础功能永久免费。AI 画像与推荐为可选增强模块。

第一步：安装运行时

下载并安装 .NET 8 Desktop Runtime（64 位）。安装包会自动检测运行环境。

第二步：下载 XFVerse

从 下载页面 获取最新安装包，解压后运行 XFVerse.exe。

第三步：添加片源

启动后进入扫描页，添加本地文件夹或配置 WebDAV 服务器地址，开始扫描即可自动识别影片。

安装与环境

系统要求

  • Windows 10 / 11（64 位）
  • .NET 8 Desktop Runtime
  • 至少 200MB 可用磁盘空间

网络依赖（可选）

  • TMDB / OMDb：自动获取影片元数据（海报、简介、演员）
  • OpenAI 兼容 API：AI 画像与推荐（可选）
核心功能完全离线可用。仅元数据搜刮和 AI 功能需要网络连接。

扫描与搜刮

本地文件夹扫描

在扫描页面选择"本地目录"，添加包含影片文件的文件夹。XFVerse 会递归扫描子目录，自动识别电影和电视剧。

文件命名建议

为提高识别准确率，建议遵循以下命名规范：

电影名称 (年份).扩展名
示例：Inception (2010).mkv

电视剧/剧名/Season 01/剧名 S01E01.扩展名
示例：Breaking Bad/Season 01/Breaking Bad S01E01.mp4

手动修正

如果自动识别结果不准确，可在媒体库中右键影片选择"修正识别"，手动搜索正确的 TMDB 条目进行绑定。

电视剧支持

识别规则与命名

XFVerse 能够自动识别电视剧，包括季数和集数。为提高识别准确率，建议采用 剧名/Season 01/剧名 S01E01.扩展名 的目录结构和文件名，以便准确匹配元数据。

剧集浏览

在媒体库中，电视剧以海报卡形式呈现。点击某个剧集进入详情页，可查看各季及每一集列表，显示已观看状态和未观看集数。

播放进度与状态同步

系统会记录每一集的播放进度与观看状态。关闭播放器后可继续从上次停留的位置播放，并在不同设备间同步已看标记。

更新监控与提醒

对追更的剧集，可以开启更新监控。软件会定期扫描新的剧集文件，一旦发现新的一季或集数，自动加入媒体库并在发现页显示更新提示。

如识别错误，可在剧集详情页使用“修正识别”手动绑定正确条目。

媒体库管理

影视墙浏览

首页以海报墙形式展示已识别的影片。支持按类型、年份、评分等维度筛选和排序。

播放源管理

每部影片可关联多个播放源（本地文件、WebDAV 远程文件）。播放时自动选择默认源。

剧集视图

剧集以季为单位分组展示，点击剧集进入详情页，可展开查看每一集的标题、时长和进度。系统会标记已观看集数，帮助你快速找到未看的内容。

浅色 / 深色主题

在设置中可切换浅色与深色双主题。播放器界面固定使用深色模式以保证沉浸感。

发现与推荐

榜单浏览

发现页提供 TMDB 热门、高分、趋势三大榜单，支持电影和电视剧分类浏览。

AI 推荐

配置 AI API 后，系统会根据你的观影记录生成个性化推荐。每部推荐附带可解释的理由。

推荐策略

采用三路并行推荐策略：观影 DNA 偏好洞察、跨类型风格探索、评分与情绪标签匹配。候选池自动去重轮转，每批推荐 3 部。

观影统计

统计总览

观影洞察页展示已看、喜爱、想看、不想看四类统计。支持全部/本月时间范围切换。

日历热力图

日历视图展示每日观影频率，颜色深浅表示观影数量。点击日期可查看当天观影记录。

图表分析

提供类型分布、情绪标签、场景分布、时段分析等多维度图表，帮助你了解自己的观影偏好。

WebDAV 配置

连接设置

在扫描页选择"WebDAV"，输入服务器地址、用户名和密码。支持 HTTP 和 HTTPS 协议。

WebDAV 密码加密存储在本地数据库中，不会上传或泄露。

流式播放

通过 WebDAV 可直接流式播放远程影片，无需下载到本地。播放体验取决于网络带宽。

AI 画像与推荐

观影人格

系统基于观影记录生成 23 种观影人格类型，包含 6 维观影 DNA 分析和口味象限定位。

API 配置

在设置页配置 OpenAI 兼容 API 端点、模型名称和 API Key。

API Endpoint: https://api.openai.com/v1
Model: gpt-4o
API Key: sk-xxxxxxxx

隐私说明

AI API 调用仅传输脱敏后的观影偏好特征（如类型偏好、评分分布），不会传输影片名称、文件路径等个人信息。
