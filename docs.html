快速开始

1. 下载安装 .NET 8 Desktop Runtime (x64)（选 Desktop Runtime → Windows x64）

2. 从 下载页面 获取 XFVerse，解压后双击 XFVerse.exe

3. 打开「扫描」页 →「本地目录」→ 添加影片文件夹 →「开始扫描」→ 返回首页查看海报墙

基础功能永久免费。AI 画像与推荐需自行配置 API。

安装与环境

系统要求

  • Windows 10 / 11（64 位）
  • .NET 8 Desktop Runtime (x64)
  • 512MB 以上内存，200MB 以上磁盘
  • 支持 DirectX 11 的显卡（mpv 硬解要求）

API 配置（可选）

以下 API 在设置页中填写，不配置不影响基本功能：

  • TMDB API — 获取海报、简介、演员、评分。内置默认 Key
  • OMDb API — 辅助元数据匹配
  • OpenAI 兼容 API — 启用 AI 画像与推荐
  • OpenSubtitles API — 在线字幕搜索
扫描、搜刮、影视墙、本地播放、观影统计均可离线使用。

首页 · 媒体库

影视墙与筛选

首页以海报墙形式展示所有已识别影片。顶部搜索栏支持按标题查找。右侧筛选区可按：

  • 类型 — 动作、剧情、科幻、喜剧等
  • 年份 — 升序或降序排列
  • 评分 — 按 TMDB 评分从高到低
  • 添加时间 — 最近添加或最早添加

每张海报显示标题、年份、TMDB 评分。鼠标悬停预览简介，点击进入详情页。

批量操作

在影视墙中按住 Ctrl 点击多张海报可多选，右键弹出批量操作菜单：

  • 批量标记已看 / 未看 — 同时修改多部影片的观看状态
  • 批量标记喜爱 / 想看 — 批量设置偏好状态
  • 移出媒体库 — 删除影片记录（不删除源文件）

状态标记说明

每张海报右下角可能显示以下标记：

  • 绿色 ✓ — 已看。播放超过 90% 自动标记，也可手动切换
  • 粉色 ♡ — 喜爱。手动标记，与「已看」可共存
  • 灰色 ☆ — 想看。未看的影片可标记为想看，加入收藏夹
  • 橙色 ✕ — 不想看。标记后不再出现在推荐中
  • 灰色边框无标记 — 未看且无偏好标记

喜爱、想看、不想看三者互斥，不能同时存在。不想看会覆盖喜爱和想看。

扫描页

本地目录

点击「本地目录」标签 →「添加文件夹」→ 选择影片所在的目录 →「开始扫描」。软件递归遍历子文件夹，自动区分电影和电视剧。扫描进度实时显示。完成后已识别的影片出现在首页，未识别的标记为「未识别」。

可添加多个文件夹，每个独立管理。分别重新扫描或移除，互不影响。

WebDAV

点击「WebDAV」标签，填写服务器地址、用户名、密码，点击「测试连接」验证，成功后点击「开始扫描」遍历远程目录。密码使用 AES 加密存储在本地数据库中。

  • 地址格式：https://example.com/dav/
  • 支持 HTTP / HTTPS，自签名证书需系统信任
WebDAV URL、账号和密码不会在日志或界面中明文展示。

文件命名建议

文件名越规范，自动识别越准确。推荐格式：

# 电影（推荐包含年份，也可仅用名称）
Inception (2010).mkv
The Matrix.mkv

# 电视剧（必须包含 SxxExx 季集编号）
Breaking Bad/Season 01/Breaking Bad S01E01.mp4
Game of Thrones S01E01.mkv

电影建议包含年份以精确匹配。电视剧必须包含季集编号。目录结构 剧名/Season XX/ 可获得最佳分组效果。

修正识别

右键媒体库中的影片 →「修正识别」→ 搜索 TMDB → 选择正确条目 → 确认。修正结果持久保存，重新扫描不会覆盖。支持：

  • 手动搜索 — 输入名称、年份在 TMDB 中搜索
  • AI 辅助 — 配置 AI API 后可启用智能匹配，自动分析文件名给出候选条目（需在设置中开启）
  • 批量修正 — 多选影片后右键可批量修正同一系列或同类型的影片
  • 特殊集处理 — SP、OVA、剧场版放在 Season 00 或 Specials 目录下，手动绑定 TMDB 特殊集条目

详情页

电影详情

点击海报进入电影详情页，包含以下区域：

  • 影片信息 — 海报、标题、年份、类型标签、TMDB/IMDb 评分
  • 简介与演员 — 剧情简介和主要演员列表
  • 播放源列表 — 所有关联的本地和 WebDAV 文件，可切换、可设默认源
  • 操作按钮 — 播放、标记已看/未看、标记喜爱/想看/不想看、修正识别
  • 无播放源 — 若没有关联文件，显示原因（文件丢失、未扫描、metadata-only）

电视剧详情

点击电视剧海报进入剧详情页：顶部显示剧集信息，下方按季切换标签页。每季展示集列表，每集显示标题、时长、已看/未看状态。已看集有绿色标记。点击未看集直接播放。

剧详情页同样有「修正识别」入口，可手动重新绑定 TMDB 条目。未识别季和已识别季共用基础布局。

播放进度

每集（或电影）独立记录播放进度：

  • 关闭播放器时自动保存当前播放位置
  • 再次打开同一影片从断点续播
  • 播放超过 90% 自动标记为「已看」
  • 可在详情页手动切换已看/未看

发现页

榜单

发现页提供 TMDB 三个榜单：热门（Popular）、高分（Top Rated）、趋势（Trending，支持今日/本周切换）。顶部可切换电影/电视剧分类。点击影片查看详情，本地已有的可直接播放，未收录的可加入「想看」。

AI 推荐

配置 AI API 后启用。每轮推荐 3 部，附带推荐理由。点击「喜欢」或「不感兴趣」反馈偏好。采用三路并行策略（偏好洞察/跨类型探索/评分匹配）生成，候选池去重后输出。

需要至少 20 部已看影片才能生成有效推荐。

观影洞察

统计总览

展示已看、喜爱、想看、不想看四类统计卡。切换「全部」/「本月」范围，趋势对比上个月。所有统计仅用本地数据计算。

日历热力图

按日展示观影频率，颜色越深当天看片越多。悬停查看当日片单，点击日期跳转观影历史。

图表分析

包含类型分布、情绪标签、场景分布、时段分析、工作日/周末对比。

需要至少 5 部已看影片才能生成图表。数据不足时显示提示。

AI 画像

配置 AI API 后可用。基于观影记录生成 23 种人格类型、6 维观影 DNA、口味象限定位、看得多 vs 真喜欢对比。需要至少 20 部已看影片。

播放器

XFVerse 使用 mpv 作为播放内核。双击影片或点击「播放」启动播放器窗口。

基本操作

  • 播放/暂停 — 空格键或点击画面
  • 快进/快退 — 方向键 ← →（5 秒），↑ ↓（60 秒）
  • 音量 — 鼠标滚轮或 9/0 键
  • 全屏 — F 键或双击画面
  • 退出 — Esc 键或关闭窗口

控制栏

底部控制栏包含：播放进度条（灰粉主色，可拖动）、播放/暂停、音量滑块、全屏按钮。鼠标移开后控制栏自动隐藏。

右键菜单

播放器窗口右键可切换：

  • 播放源 — 如果影片有多个文件，可切换不同分辨率/来源
  • 音轨 — 切换多音轨（如国粤双语、导演评论）
  • 字幕 — 内嵌字幕 / 外挂字幕 / 在线下载字幕（需配置 OpenSubtitles API）

在线字幕

右键 → 字幕 → 在线下载字幕。搜索 OpenSubtitles 数据库，选择匹配的字幕文件下载并自动加载。下载的字幕缓存到本地，可在设置 → 缓存管理中清理。

播放器窗口固定使用深色模式，不跟随主界面主题切换。在线字幕功能需配置 OpenSubtitles API。

设置页

主题切换

设置页顶部可切换浅色/深色主题。播放器不受此设置影响，固定深色。设置即时生效，无需重启。

API 配置

在「API 配置」区域填写各服务的 Key：

# AI 画像与推荐
API Endpoint: https://api.openai.com/v1
Model: gpt-4o
API Key: sk-xxxxxxxx

# 也支持 DeepSeek
API Endpoint: https://api.deepseek.com/v1
Model: deepseek-chat

填写后点击「测试连接」验证。密码/Token 类字段默认隐藏，点击眼睛图标显示。

AI API 调用仅传输脱敏的偏好特征，不传影片名、文件路径、个人信息。结果缓存避免重复调用。

缓存管理

设置页底部「软件缓存管理」可查看和清理：

  • 海报缓存 — TMDB 海报图片
  • Metadata 缓存 — 影片元数据
  • 在线字幕缓存 — 下载的字幕文件（仅清理孤立缓存，被引用的字幕受保护）

每项显示容量和文件数。清理缓存不删除本地影片文件和用户配置。
